# Hands-on-packet-capture-with-Wireshark
This project will encompass a comprehensive examination of packet capture methodologies, with particular emphasis on the utilization of Wireshark as a powerful tool for capturing, analyzing, and interpreting network traffic. Participants will be guided through the setup and configuration of packet capture environments, the process of capturing packets in real-time, and the analysis of captured packet data to extract meaningful insights. Additionally, the project will explore the application of packet capture in the context of cryptography, highlighting its relevance in detecting cryptographic attacks and assessing the security posture of cryptographic protocols.
